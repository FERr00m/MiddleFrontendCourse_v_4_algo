# Домашнее задание (24.09)

Необходимо реализовать фронт часть одного из проектов по визуализации файловой структуры. (такое часто бывает на хостингах, когда отображается ФС)

Инструмент можно использовать любой (react, vue, angular, native…),визуальный стиль тоже на ваше усмотрение, но без излишеств

Данные приходят в json-формате и примером может служить прикрепленный файл. Данные можете сервить любым удобным для вас способом

Главная цель - отображать такую структуру в браузере с визуальным разграничением папок от файлов (можно иконками). Алгоритм должен быть максимально гибким - количество и вложенность может быть любой. Дополнительно можно реализовать маршрутизацию по папкам (клик на папку вызывает смену url и отображение только её внутренностей)

Загрузить проект на github ОБЯЗАТЕЛЬНО В ПРОЕКТ ГДЕ ГЛАВНАЯ ВЕТКА ПУСТАЯ, а код в рабочей ветке. Сама проверка будет завтра

Данные брать из этого файлика (его можно и засервить)(Если у вас нет опыта в запуске сервера - напишите в чат, поможем)
